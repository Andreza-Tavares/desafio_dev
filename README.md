# 🚀 Desafio de Desenvolvimento

Este repositório contém a solução estruturada para o desafio de desenvolvimento.

## 🛠️ Tecnologias e Arquitetura

* **C# & .NET:** Utilizado para criar a API e o back-end da aplicação.
* **HTML & CSS:** Utilizados para estruturar e estilizar os componentes do front-end.
* **Visual Studio:** Ambiente onde o projeto foi desenvolvido, compilado e onde o executável foi gerado.

---

## ⚙️ Como Funciona a Execução

O projeto foi estruturado de forma que o código-fonte permaneça organizado no Visual Studio, enquanto um script automatizado (`Desafio.bat`) foi criado na raiz para facilitar a abertura sem a necessidade de rodar o Visual Studio na maquina.
